What this GitHub Pages site is — and isn't

This is the project's static website and documentation entry point. The actual workbench runs locally with Node.js because verification and upload operations require a private server-side API connection. GitHub Pages cannot host that backend or safely hold your API credentials.

GET STARTED

Run SheerFlow on your machine.

Start with the offline demo. Connect your own authorized SheerID API application only when you have program access.

1

Clone the repository

git clone https://github.com/voyager67/Sheerid-Workflow-Studio.git
cd Sheerid-Workflow-Studio
2

Install dependencies

npm ci

Requires Node.js 22.15 or newer.

3

Configure local demo mode

cp .env.example .env

Set SHEERFLOW_MODE=demo and choose a unique dashboard password of at least 20 characters in your local .env.

4

Start the workbench

npm start

Open http://127.0.0.1:8787 in your browser.

FOR AUTHORIZED OPERATORS

Connect your own API application

Live mode requires a published SheerID program and credentials provisioned for your organization. SheerFlow does not supply or share API keys.

  • Obtain API Access in MySheerID.
  • Create an authorized Client Application.
  • Set your own Client ID, Client Secret and Program ID in .env.
  • Validate with provider Test Mode before production use.
